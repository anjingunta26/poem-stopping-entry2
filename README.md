## What it does

`main.py` writes a short poem (max 280 code points) about agency —
the power to STOP and stay STILL while one agent acts for another —
to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Run

```sh
python3 main.py
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py   # custom output dir
```
